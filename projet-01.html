Modèle de scoring crédit

Algorithmes de classification pour l'octroi de crédits à la consommation
Classification binaire Feature Engineering SHAP Optimisation métier

Contexte & Problématique

Au cours de ce projet, on se positionne en tant que Data Scientist travaillant pour une société financière fictive. L'objectif est de concevoir un outil de scoring crédit capable de calculer la probabilité de remboursement d'un client et de classifier automatiquement les demandes (crédit accordé / refusé).


Le modèle doit être facilement interprétable pour les chargés de relation client, et tenir compte d'un déséquilibre de coût métier : un faux négatif (crédit accordé à un mauvais payeur) est 10× plus coûteux qu'un faux positif (bon client refusé).

Démarche

  • Analyse exploratoire du dataset Home Credit Default Risk : outliers, valeurs manquantes, distributions
  • Feature engineering : création de nouvelles variables pertinentes (taux de paiement, retards moyens, etc.)
  • Conception d'un score métier pénalisant les faux négatifs (×10). Objectif des modèles : minimiser le score métier
  • Benchmark de 5 modèles avec pipelines scikit-learn, Cross-Validation 5-folds et GridSearchCV
  • Gestion du déséquilibre de classes : beaucoup plus de crédits accordés que refusés dans la base de données
  • Optimisation du seuil de décision par minimisation du coût métier
  • Interprétabilité globale et locale du modèle avec SHAP

Pipeline de modélisation

EDA→ Feature Engineering→ Preprocessing→ Rééquilibrage classes→ GridSearchCV (5-folds)→ Optimisation seuil→ Interprétation modèle

Interprétabilité du modèle : utilisation de la librairie Python SHAP

Globale : les variables les plus influentes sur l'ensemble du jeu de données sont EXT_SOURCE_2, EXT_SOURCE_3 (scores externes fournis dans le jeu de données), ainsi que des variables créées lors du feature engineering, telles que PAYMENT_RATE (taux de remboursement) et INSTAL_DPD_MEAN (retards moyens).


Locale : les valeurs SHAP permettent d'expliquer chaque prédiction individuelle — les variables en faveur du remboursement (classe 0) et celles signalant un risque de défaut (classe 1).
