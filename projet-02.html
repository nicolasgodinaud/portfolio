PROJET 02 · COMPUTER VISION & NLP

Classification automatique d'images d'articles e-commerce

Moteur de classification automatique par image et description texte
NLP Computer Vision Transfer Learning Clustering

Contexte & Problématique

Dans ce projet, on travaille pour une marketplace e-commerce fictive, sur laquelle les catégories de produits étaient jusqu'alors attribuées manuellement par les vendeurs — source d'erreurs et frein au passage à l'échelle. L'objectif est d'étudier la faisabilité d'un moteur de classification automatique des articles à partir de leur image et de leur description texte, puis de développer un modèle supervisé de classification d'images.


Le dataset comprend 906 produits, répartis en 7 catégories : Watches, Computers, Home Furnishing, Kitchen & Dining, Beauty & Personal Care, Home Decor, Baby Care.

Démarche

  • Prétraitement des descriptions texte et des images produits
  • Extraction de features texte : BoW, TF-IDF, Word2Vec, BERT, USE
  • Extraction de features image : descripteurs SIFT et CNN Transfer Learning (VGG16)
  • Réduction dimensionnelle PCA + t-SNE pour visualisation 2D
  • Clustering K-Means + calcul ARI pour évaluer la faisabilité
  • Classification supervisée par CNN : from scratch, Transfer Learning, + Data Augmentation
